# Asset Placeholders

This directory contains app assets:

- `icon.png` - App icon (1024x1024)
- `adaptive-icon.png` - Android adaptive icon foreground (1024x1024)
- `splash.png` - Splash screen image (1284x2778 recommended)
- `favicon.png` - Web favicon (48x48)

## Creating Assets

You can generate placeholder assets using tools like:
- https://www.appicon.co/ for app icons
- https://www.figma.com/ for custom designs
- https://unsplash.com/ for placeholder images

For development, you can use simple colored squares as placeholders.
